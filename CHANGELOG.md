# Changelog

## [0.1.0] — 2026-11-08

Initial playable GitHub release of the Feirmeoir digital board-game adaptation.

### Includes

- Solo play and two-to-four-player local pass-and-play.
- Farm setup, worker placement, home and village cards, harvesting, scoring, and local saves.
- Standalone self-contained offline HTML with embedded card artwork and original rules PDF.
- Static website suitable for GitHub Pages or another web host.
- Artwork/card inventory verifier and 14 Node.js rules checks.
- Repository documentation, screenshots, and CI and Pages workflows.

### Known limitations

- No computer opponents, online multiplayer, or cross-device save syncing.
- Offline local-file save support varies by browser.
- Some ambiguous or damaged wording in the supplied board-game rules is resolved by documented digital-adaptation rulings; author review remains useful.
